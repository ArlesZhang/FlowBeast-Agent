# FlowBeast Project Rules

> Core project philosophy and guiding principles

## Project Overview

FlowBeast is a **Content Factory**: transforming classic literature into AI Manju (漫剧) — AI-generated visual storytelling. The core moat is the **9-skill workflow** — a proven methodology for deconstructing source material, designing visual narratives, and producing AI-ready prompt packages.

**Current Status:** Case Study #001 Complete (Pride & Prejudice — Darcy Rain Confession)

**Current Phase:** Phase 2 — Video Production
- Import `prompt_package.json` into Jimeng AI (即梦) / Seedance / Kling
- Generate 48 shots with consistent characters and style
- Assemble 2-minute video
- Publish and gather feedback

**Future Phases:**
- Phase 3: Template refinement based on learnings
- Phase 4: Case Study #002 (Romeo & Juliet / Monte Cristo / Les Misérables)
- Phase 5: Workflow productization (future)

## Core Principles

The assistant must:
- **Focus on production, not infrastructure** — This is a content workspace, not a Python project
- **Maintain character consistency** — The #1 quality metric for AI-generated video
- **Preserve emotional core** — Story and emotion over technical sophistication
- **Iterate based on feedback** — Real viewer response informs improvements
- **Build reusable methodology** — Every case study becomes a template for the next

## Project Priorities

1. **Production over perfection** — Ship the video, gather real feedback
2. **Character consistency is king** — Regenerate shots if faces/costumes drift
3. **Emotional impact over technical polish** — Does it move the viewer?
4. **Fast iteration** — Test with 30-second clip before full assembly
5. **Document learnings** — Retrospective informs next case study

## Understanding the Project

The assistant should understand:
- This branch focuses on **content creation**, not code
- All Python infrastructure is archived in `main` and `develop` branches
- The 9-skill workflow has been proven and is reusable
- The immediate goal is video generation, not more templates or skills
- Quality is measured by viewer engagement, not technical metrics

## Content Production Guidelines

When assisting with video production:
- Prioritize character consistency across all shots
- Ensure style lock adherence (semi-realistic anime, period-accurate)
- Verify emotional beats land correctly (expressions match the script)
- Check visual quality (lighting, rain effects, composition)
- Suggest regeneration if quality issues are found

When assisting with template refinement:
- Focus on what worked and what didn't in Case Study #001
- Update templates to be more efficient and effective
- Document specific improvements and why they matter
- Prepare templates for Case Study #002

When assisting with Case Study #002:
- Apply the proven 9-skill workflow
- Use refined templates from Case Study #001
- Work faster and more efficiently based on learnings
- Maintain the same quality standards

## Prohibitions

Never:
- Write Python code (this is not a Python project on this branch)
- Propose building new infrastructure or frameworks
- Suggest adding dependencies or tools not needed for video production
- Over-engineer the workflow (9 skills are proven, don't add more)
- Distract from the immediate goal (video generation)

## Optimization Targets

The project is optimized for:
- **AI-assisted content production** (Claude Code as creative collaborator)
- **Character consistency** (the #1 quality metric)
- **Emotional storytelling** (does it move the viewer?)
- **Reusable methodology** (every case study becomes a template)
- **Fast iteration** (test, learn, improve, repeat)
