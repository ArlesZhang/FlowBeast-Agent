## ADR 命名规范

- 文件名: `000N-title-with-hyphens.md`
- 编号: 4 位数字，自增
- 标题: 简洁描述决策主题

## 状态流转

```
Proposed → Accepted / Rejected → Deprecated → Superseded by NNN
```
