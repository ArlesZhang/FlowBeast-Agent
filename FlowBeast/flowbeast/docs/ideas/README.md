# Ideas Directory

This directory contains working notes, brain dumps, and exploratory thoughts.

## Guidelines

- **Think loosely, write quickly** - These are rough ideas, not final products
- **Delete when implemented** - Once an idea becomes code, delete the note
- **Move to decisions/ when**:
  - The idea has been vetted
  - Trade-offs have been considered
  - A concrete plan is ready

## Example Notes

```
ideas/
├── fp3-optimization.md      # RAG performance thoughts
├── async-streaming.md       # Streaming response ideas
└── multi-tenant.md          # Multi-user architecture sketch
```

## When to Delete

1. Implementation is merged
2. Idea is rejected as non-viable
3. Idea is moved to a proper ADR in `decisions/`

## Not For

- Production-ready documentation
- API specifications
- Architecture decisions (use `decisions/`)
- User-facing guides (use `README.md`)
