# 04_scene_design/

Break the script into visual scenes.

## Output Files

| File | Purpose |
|------|---------|
| `scene_breakdown.md` | Scene list with location, time, mood |
| `pacing_notes.md` | Beat timing, pauses, reveals |

## Focus

- Define location (Pemberley gardens? Hunsford parsonage?)
- Define time of day (evening rain? morning storm?)
- Define atmosphere (tension, isolation, vulnerability)
- Define pacing (slow build → explosive confession → painful rejection)
