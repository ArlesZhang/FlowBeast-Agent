# 03_adaptation/

Transform literary prose into AI-manju script.

## Output Files

| File | Purpose |
|------|---------|
| `adaptation_strategy.md` | What to keep, change, amplify for AI manju |
| `script.md` | Final adapted script (dialogue + action) |
| `notes.md` | Adaptation decisions and rationale |

## Key Decisions

- How to condense a 20-page chapter into 2-minute short drama
- How to preserve Austen's emotional core while making it visual
- How to handle internal monologue (Darcy's pride, Elizabeth's prejudice)
