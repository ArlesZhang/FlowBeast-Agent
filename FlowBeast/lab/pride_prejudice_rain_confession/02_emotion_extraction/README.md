# 02_emotion_extraction/

Map the emotional landscape of the rain confession scene.

## Output Files

| File | Purpose |
|------|---------|
| `emotion_map.md` | Character emotion states per scene moment |
| `emotional_curve.md` | Visual curve: tension → climax → resolution |
| `conflict_structure.md` | Internal/external conflict breakdown |

## Focus

- Track how Elizabeth and Darcy feel at each beat
- Identify when feelings shift and what drives those shifts
- Map the emotional arc from pride → shock → anger → vulnerability
