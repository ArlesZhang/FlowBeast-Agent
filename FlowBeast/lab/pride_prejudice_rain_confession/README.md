## Next Phase: Video Production

### Priority 1: Generate 48 Shots with Jimeng AI (即梦)

**Immediate Action:**
1. Open `08_prompts/prompt_package.json`
2. Import into Jimeng AI / Seedance / Kling
3. Generate shots one by one using the prompts
4. Review each shot for:
   - Character consistency (Elizabeth & Darcy look the same across shots)
   - Style consistency (semi-realistic anime, period-accurate costumes)
   - Emotional accuracy (expressions match the beat)
   - Visual quality (lighting, rain effects, composition)

**Quality Checklist:**
- [ ] Elizabeth's face consistent across all shots
- [ ] Darcy's face consistent across all shots
- [ ] Costumes remain identical (no drift)
- [ ] Darcy's coat stays wet throughout
- [ ] Rain intensity matches the beat (gentle → heavy → storm → softer)
- [ ] Lighting remains overcast/gray (no sunlight)

### Priority 2: Verify Character Consistency

**Critical Check:**
- Compare Elizabeth in S02 (reading) vs S48 (collapse)
- Compare Darcy in S04 (doorway) vs S46 (departure)
- Check for face morphing, costume changes, expression mismatches

**If inconsistencies found:**
- Regenerate problematic shots with stronger negative prompts
- Use character reference images if platform supports
- Adjust prompt weights on character descriptions

### Priority 3: Create 30-Second Test Clip

**Selection:** Choose 10-12 key shots that showcase:
- Opening tension (S01-S06)
- Confession vulnerability (S10-S12)
- Explosive refusal (S28-S32, S38)
- Devastated departure (S44-S48)

**Purpose:** Test the workflow before committing to full 48-shot assembly

### Priority 4: Assemble Full 2-Minute Video

**Steps:**
1. Sequence all 48 shots according to `shot_list.md`
2. Add transitions (cuts, as specified)
3. Add sound design:
   - Rain (varying intensity per beat)
   - Thunder (S09, S18, S28, S38)
   - Dialogue (if voice generation available)
   - Score (melancholic piano, building tension)
4. Final color grading (cool, desaturated, cinematic)
5. Export in 16:9, 1080p or 4K

### Priority 5: Publish and Gather Feedback

**Platforms:**
- Douyin (抖音)
- Bilibili (B站)
- Xiaohongshu (小红书)
- YouTube Shorts

**Feedback to gather:**
- Does it capture the emotional core?
- Is it "not cheesy/melodramatic" (不狗血烂俗)?
- Would viewers watch to the end?
- Would viewers share it?
