# Case Study #001: Pride & Prejudice — Darcy Rain Confession

**Goal:** Produce a market-ready AI Manju (漫剧) prompt package for the iconic rain confession scene from Jane Austen's *Pride and Prejudice*.

**Scope:** Content layer (A) + Director layer (B) only. No video/audio generation code.

**Timeline:** 
- Story analysis: Week 1
- Emotion extraction: Week 1-2
- Adaptation & scene design: Week 2-3
- Storyboard & character bible: Week 3-4
- Style lock & prompt engineering: Week 4-5
- Asset generation & retrospective: Week 5-6

---

## Directory Structure

```
01_story_analysis/     — Deconstruct the original novel chapter
02_emotion_extraction/ — Map emotional states and conflict structure
03_adaptation/         — Transform prose into AI-manju script
04_scene_design/       — Break script into visual scenes
05_storyboard/         — Design every shot: framing, motion, camera
06_character_constraints/ — Character bible for AI consistency
07_generation_rules/   — Visual style, negative prompts, platform specs
08_prompts/            — Final prompt package for AI video tools
```

---

## Success Criteria

- [ ] `story_analysis.md` answers the four core questions
- [ ] `prompt_package.json` is exportable to Seedance/Kling/HeyGen
- [ ] Character consistency maintained across all shots
- [ ] Emotional arc preserved from source material
- [ ] Retrospective captures lessons for future case studies
