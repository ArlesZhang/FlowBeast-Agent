# Consistency Rules: Darcy's Rain Confession
**Purpose:** Ensure AI-generated characters and scenes remain consistent across all shots

---

## Global Consistency Rules

### Character Continuity
- **Same actors** throughout (no face changes)
- **Same costumes** throughout (no outfit changes)
- **Same hairstyles** throughout (no hair changes)
- **Same physical features** throughout (no eye color, hair color, build changes)

### Scene Continuity
- **Same location** throughout (Hunsford parsonage, sitting room)
- **Same lighting** throughout (overcast, gray, diffused)
- **Same weather** throughout (rain, varying intensity)
- **Same props** throughout (furniture, books, fireplace)

### Temporal Continuity
- **Continuous action** (no time jumps)
- **Consistent wetness** (Darcy's coat stays wet)
- **Consistent weather progression** (rain intensifies, then softens)

## Prompt Engineering Rules

### Always Include in Prompts
- [ ] Character descriptions (from character bibles)
- [ ] Costume details (specific, detailed)
- [ ] Expression tags (emotion: [specific emotion])
- [ ] Scene details (Hunsford parsonage, rain, overcast)
- [ ] Lighting details (gray, diffused, no sunlight)
- [ ] Wetness details (Darcy's coat wet, hair damp)

### Never Include in Prompts
- [ ] Modern elements (phones, modern clothing, modern hairstyles)
- [ ] Anachronisms (wrong period details)
- [ ] Visual noise (text, watermarks, UI elements)
- [ ] Style violations (wrong art style, wrong lighting)
- [ ] Contradictions (dry coat, different dress, different face)

### Negative Prompts (Always Include)
```
modern clothing, modern hairstyles, modern makeup, modern accessories,
smartphone, laptop, contemporary furniture, electric lights,
wrong period costume, wrong hairstyle, wrong eye color, wrong hair color,
face changes, costume changes, lighting changes, weather inconsistency,
text, watermark, signature, logo, UI elements,
deformed face, extra fingers, deformed hands, blurry face,
sunlight, direct sun, warm lighting, candles, fire in fireplace,
dry coat, dry hair, clear sky, no rain
```

### After Generating All Shots
- [ ] Review all shots side-by-side
- [ ] Check for face drift across shots

## Troubleshooting Common Issues

### Issue: Face Changes Between Shots
**Solution:** Use same face reference image, increase face consistency weight, use face lock feature if available

### Issue: Costume Changes
**Solution:** Include detailed costume description in every prompt, use costume reference image

### Issue: Expression Mismatch
**Solution:** Use specific emotion tags, provide expression reference images, adjust prompt weight on expression

### Issue: Darcy's Coat Dries
**Solution:** Include "wet coat, dripping water" in every Darcy prompt, use wetness reference image

### Issue: Lighting Changes
**Solution:** Include "overcast, gray, diffused light" in every prompt, use lighting reference image

### Issue: Rain Inconsistency
**Solution:** Include rain intensity in every prompt (gentle/heavy/storm), use rain reference image

## Final Notes

Consistency is the **single most important factor** in AI-generated visual storytelling. Inconsistent characters, costumes, or scenes will break immersion and make the story unwatchable.

**Key principles:**
1. **Detailed descriptions** in every prompt
2. **Reference images** for faces, costumes, expressions
3. **Negative prompts** to prevent common errors
4. **Quality control** after every shot
5. **Side-by-side review** after all shots

**When in doubt, regenerate.** It's better to spend time getting consistency right than to accept inconsistent shots.
