## Why Scene Lock Matters

Scene inconsistency is the **second biggest failure point** in AI visual storytelling (after character inconsistency). Without a locked scene reference:

- Furniture changes style between shots
- Room size expands or shrinks
- Lighting shifts from overcast to sunny
- Rain disappears from windows
- Props vanish or appear randomly
- Color temperature drifts warm/cool

**Every shot must look like it was filmed in the SAME room, at the SAME time, in the SAME weather.**

## Troubleshooting

### Issue: Room Looks Different Between Shots
**Solution:** Use the wide-angle room reference image in every prompt. Increase background consistency weight. Include detailed room description in every prompt.

### Issue: Lighting Shifts Warm
**Solution:** Include "overcast, gray, cool lighting, no warm light" in every prompt. Use lighting reference image. Check that no fire/candles/sunlight appear.

### Issue: Rain Disappears
**Solution:** Include rain intensity description in EVERY prompt (not optional). Use rain-on-window reference image. Check weather against beat progression table.

### Issue: Furniture Changes Style
**Solution:** Include specific furniture descriptions (Regency style, modest, dark wood). Use room reference image. Add "consistent furniture style" to prompt.

### Issue: Props Disappear or Move
**Solution:** Track prop states per beat. Include prop descriptions in relevant shot prompts. Check prop checklist after each generation.

### Issue: Room Size Changes
**Solution:** Include "small, modest sitting room" in every prompt. Use wide-angle room reference. Avoid wide-angle lenses that distort room size.

## Final Notes

Scene consistency is not optional. It is the **visual foundation** that makes character performances believable. If the room changes, the audience's immersion breaks — even if the characters are perfectly consistent.

**Key principles:**
1. **Lock the room** before generating any shots
2. **Reference the room** in every single prompt
3. **Check the room** after every single generation
4. **Regenerate** if the room doesn't match

The sitting room is the **third character** in this scene. It must be as consistent as Elizabeth and Darcy.
