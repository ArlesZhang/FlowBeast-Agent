# 05_storyboard/

Design every shot: framing, motion, emotional beat, camera work.

## Output Files

| File | Purpose |
|------|---------|
| `shot_list.md` | Per-shot: framing, motion, emotion beat |
| `camera_directions.md` | Specific camera movements and angles |
| `visual_references/` | Mood boards, reference images |

## Focus

- This is the director's vision
- Every shot must serve the emotional arc
- Camera work amplifies tension (close-ups, wide shots, rain effects)
