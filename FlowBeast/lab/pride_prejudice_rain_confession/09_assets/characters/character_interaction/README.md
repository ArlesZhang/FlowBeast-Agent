## Why Interaction Assets Matter

Individual character assets ensure each person looks consistent. But AI tools often generate characters in **different styles** when they're in the same image. Interaction assets ensure:

1. **Same art style** for both characters
2. **Correct relative height** (Darcy 6'0", Elizabeth 5'4")
3. **Correct relative build** (Darcy athletic, Elizabeth slender)
4. **Same lighting treatment** on both characters
5. **Correct spatial relationship** (proximity, facing direction)
