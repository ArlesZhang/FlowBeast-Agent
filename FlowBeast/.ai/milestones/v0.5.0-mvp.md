## How to Run

### CLI Pipeline
```bash
# Default topic (hardcoded xianxia)
python main.py

# Custom topic
python main.py --topic "AI Agent 取代白领"
```

**Output:** `flowbeast/data/outputs/{run_id}/`
- `script.json` — Generated drama script
- `prompt_package.json` — Complete asset package for video tools
- `production_report.json` — Quality metrics, FP3 usage, timing
- `episode_audio.mp3` — Full episode audio (edge-tts)

### FastAPI Server
```bash
uvicorn flowbeast.api.main:app --reload --port 8000
```

**Endpoints:**
- `POST /api/v1/generate` — Submit generation task (returns `task_id`)
- `GET /api/v1/tasks/{task_id}` — Poll task status (includes GRAFT metadata)
- `GET /api/v1/download/{file_type}/{run_id}` — Download assets

**Example:**
```bash
# Submit task
curl -X POST http://localhost:8000/api/v1/generate \
  -H "Content-Type: application/json" \
  -d '{"topic": "AI Agent 取代白领", "use_graft": true}'

# Check status
curl http://localhost:8000/api/v1/tasks/{task_id}
```

### Streamlit Demo UI
```bash
uv run streamlit run flowbeast/demo/app.py --server.port 8501
```

**Features:**
- Topic input with recommended topics
- Real-time task status polling
- GRAFT structure visualization (Hook + Conflict)
- Generated script display with scenes
- Audio player for episode audio
- Download buttons for all assets

### Test Suite
```bash
uv run pytest tests/ -q
```

**Result:** 67 tests passed (58 existing + 9 new GRAFT tests), zero regressions.

## GRAFT v0: The Core Innovation

**What GRAFT Does:**
1. Retrieves the best-matching ViralScript from FP3
2. Extracts **Hook Structure** (type, opening pattern, emotional payload)
3. Extracts **Conflict Pattern** (type, escalation curve, reversal mechanics)
4. Builds a **structural transfer prompt** with 5 migration instructions
5. Forces the LLM to apply these viral structures to the new topic

**Why It Matters:**
- Original generation follows default templates
- GRAFT-enhanced generation follows **proven viral structures**
- The difference is visible: different hook types, conflict engines, escalation curves

**Evidence:**
All 5 evidence runs show consistent GRAFT application:
- Hook Type: `冲突爆发` (Conflict Explosion)
- Conflict Type: `权力碾压` (Power Oppression)
- Escalation Curve: `压抑 → 升级 → 爆发 → 反转`

## Architecture Summary

```
User Topic
  ↓
GRAFT Operator (flowbeast/vto/graft.py)
  ↓
FP3 Retriever (retrieves best ViralScript)
  ↓
Extract Hook + Conflict Structures
  ↓
Build GRAFT Prompt (structural transfer instructions)
  ↓
Drama Generator (flowbeast/drama/generator.py)
  ↓ (with custom_prompt = GRAFT prompt)
LLM Call (qwen3.6-plus via Anthropic gateway)
  ↓
Generated Script (JSON)
  ↓
QualityGate (score ≥ 0.45 → ACCEPT, ≥ 0.40 → REVIEW, < 0.40 → REJECT)
  ↓
Shot Director (flowbeast/drama/shot_director.py)
  ↓
Asset Manager (flowbeast/drama/asset_manager.py)
  ↓
Prompt Package Export (prompt_package.json)
  ↓
Audio Generation (edge-tts, 15-22 lines per episode)
  ↓
Episode Assembly (episode_audio.mp3)
  ↓
Production Report (production_report.json)
```
