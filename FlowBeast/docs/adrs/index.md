# Architecture Decision Records (ADRs)

ADRs document important architectural decisions in FlowBeast.

## Decision Status

| Status | Meaning |
|--------|---------|
| `Proposed` | Decision under consideration |
| `Accepted` | Decision approved and implemented |
| `Deprecated` | Old decision, replaced by newer ADR |
| `Superseded by NNN` | Replaced by another ADR |
