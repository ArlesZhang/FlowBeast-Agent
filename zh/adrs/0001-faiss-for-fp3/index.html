    0001 - FP3 使用 FAISS 向量库¶

    Date: 2026-04-28

    Status¶

    Accepted

    上下文¶

    FP3 子系统需要一个向量数据库来支持 RAG（Retrieval-Augmented Generation）功能。

    需求： - 轻量级，适合单机部署 - 支持中文文本嵌入 - 可嵌入 Python 应用（无需独立服务） - 快速检索（毫秒级）

    决策¶

    选用 FAISS 作为 FP3 的向量存储后端。

    具体实现： - 使用 faiss.IndexFlatL2 进行精确检索 - 嵌入维度: 1536 (兼容 OpenAI embedding-ada-002) - 索引保存为 .faiss 文件，支持持久化加载

    后果¶

    正面¶

    • 零依赖部署: 无需启动额外的数据库服务
    • 检索速度: 毫秒级响应（10k 规模内）
    • Python 友好: 原生 Python API，调试友好

    负面¶

    • 内存限制: 全量索引需载入内存（100k 条目约 3GB）
    • 无分布式: 单机方案，不支持水平扩展
    • 功能有限: 不支持复杂查询

    考虑的备选方案¶

    备选方案 1: Chroma¶

    为什么拒绝: 需要启动独立的 Chroma 服务（gRPC），增加了部署复杂度。

    备选方案 2: Qdrant¶

    为什么拒绝: 功能强大但需要单独部署。可以在 FP3 v0.4+ 评估迁移。
